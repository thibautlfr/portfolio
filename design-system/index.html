Principles

01

The sheet is the layout

White cells bounded by hairlines on a gray ground. Structure is drawn by the content's own edges, never by a decorative grid.

The frame is quiet, the works are loud

Type, colour and space stay sober. Colour comes from the shader, the project visuals and the posters.

Engineering first

Data is set as data, in mono with tabular figures. Facts come before adjectives, and nothing is claimed that is not shown.

One continuous motion

The hero shader moves. Everything else answers the visitor briefly and stops.

Accessible by construction

Every colour pair is measured against WCAG 2.2 AA on this page, motion stops under reduced motion, and every image has its alt text.

Contrast

Measured at build time against WCAG 2.2 AA: 4.5 for text at body size, 3 for lines and frames. The last two pairs fail and are never used. A test keeps both lists honest: it fails when a used pair stops meeting the standard, and when a refused pair starts to.

Motion

05

Dry and short: the hero shader is the only continuous motion. Durations drop to zero under reduced motion, so nothing below moves for a visitor who asked for that. Where there is a pointer, hover a cell to run it.

Images

07

Every image sits in its cell with a hairline frame, which turns teal on hover where the image leads somewhere. Artworks are shown at their own ratio. The cover is the project as it is, captured and set in the sheet; only the loops and figures that explain how something works are drawn in the site's own language. The reason is in a note on why the system leaves some things alone.

Beyond the page

08

The system is built to travel: anything made around the site starts from the same tokens. Two of the places it already runs are below.

Monogram

Avatars and small marks. The square is the text colour.

Open Graph card

Drawn at build time, in the same cells, faces and colours.

The site
Reads the tokens as custom properties. Stylelint rejects a raw colour, size or duration anywhere else.
Project media
Covers, loops and figures are drawn on a development page that loads the same tokens, fonts and shader palette.
Open Graph cards
The renderer cannot read custom properties, so seven colours are copied by hand, and a test compares them with the stylesheets.
Documents and slides
White cells, one-pixel hairlines in the line colour, titles in Headline and data in mono. The five faces are open source (SIL Open Font License), so they install anywhere.
