# French and English

The plan for making the site bilingual, and where it stands. Read it at the start of any session that touches the migration, tick a box when its step is done, and keep the log at the bottom short. When the last phase is done, the decisions move into `docs/architecture.md` and `docs/content.md`, and this file is deleted.

## Decisions

- **Everything is bilingual**, notes included, except `/design-system/`, the media kit, `llms.txt` and the RSS feed, which stay in English. Translations are written with AI and reread by Thibaut.
- **URLs.** English stays at the root, so no indexed link breaks; French lives under `/fr/` with the same slugs (`/fr/work/youbook/`). Slugs stay in English in both languages. Astro's built-in i18n routing, `prefixDefaultLocale: false`.
- **No automatic redirect.** GitHub Pages has no server, and a script redirect hurts search engines and visitors whose browser language is not their reading language. Instead: `hreflang` alternates on every page, posts link to the right language, and a switch leads to the same page in the other language.
- **The switch** reads `EN / FR`. It sits in the hero on the home page, at the end of the breadcrumb bar on inner pages, and in the footer.
- **A one-time hint** (phase 6): on an English page, when the browser prefers French, a discreet line offers the French page. Dismissed or followed, it never comes back (localStorage).
- **Content files.** A French entry is a sibling of the English one: `index.mdx` and `index.fr.mdx` in the same folder, sharing its media. The French file holds only what is translated (title, summary, decisions, figure labels, alt texts, body); stack, links, dates and media come from the English file.
- **UI copy** lives in one typed dictionary, `src/i18n/ui.ts`: a key missing in one language fails `astro check`.
- **The recommendation** shows Nicolas Péridont's original French text on the French site, and the translation on the English one.
